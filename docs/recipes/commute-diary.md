# Recipe: 자전거 출퇴근 일기

영문 문서는 [commute-diary-en.md](commute-diary-en.md)를 참고하세요.

## 목적

비슷한 집-직장 코스를 반복해서 달릴 때도 매일 달라지는 몸 상태, 날씨, 교통, 자전거 상태와 짧은 일기를 활동 옆에 남깁니다. 한 주가 끝나면 같은 코스의 이동 시간과 체감 변화를 함께 보며 반복되는 패턴을 찾습니다.

이 레시피는 관계를 돌아보는 개인 기록 도구입니다. 건강 상태를 진단하거나 사고 예방을 보장하지 않으며, 숫자가 라이더의 느낌보다 더 정확하다고 가정하지 않습니다.

## 필요한 scope

- `activities:read`: 본인의 날짜, 시간, 거리, 이동/경과 시간, 속도, 상승고도 같은 활동 요약을 읽습니다.

정확한 경로 좌표는 필요하지 않으므로 `streams:read`를 요청하지 않습니다. 날씨·교통·몸 상태·일기는 라이더가 직접 입력하는 개인 메모입니다.

## 기록 흐름

### 출발 전 60초

- 출근/퇴근, 자전거, 익숙한 코스인지 또는 우회 예정인지
- 수면·회복, 에너지, 기분, 스트레스: 간단한 5점 척도
- 통증이나 불편감: 선택 입력
- 날씨와 예상되는 도로 위험
- 헬멧·타이어·브레이크·체인·라이트 빠른 확인

### 도착 후 2분

- 자동 기록: 날짜, 출발·도착 시각, 거리, 이동/경과/정차 시간, 속도, 상승고도
- 선택 지표: 평균 심박, 파워, 케이던스처럼 이미 활동 요약에 포함된 값
- 실제 피로·호흡·통증·집중도와 도착 후 기분
- 교통 체감, 우회, 아차 사고나 장비 문제
- 오늘 잘한 한 가지, 다음 이동에서 바꿀 한 가지, 기억하고 싶은 한 장면

### 주간 회고

- 자출 일수와 총 거리, 출근/퇴근 비율
- 같은 코스의 이동 시간과 체감 변화
- 낮은 안전 체감이나 높은 피로가 반복된 시간대·날씨·개인 메모
- 점검이나 정비가 필요한 항목과 가장 편안했던 조건
- 다음 주에 유지할 점과 바꿀 점

휴식이나 대중교통 이용은 끊긴 연속 기록이나 실패로 표시하지 않고 회복 또는 이동 선택으로 남깁니다.

## 데이터 흐름

1. Personal Data API에서 본인의 활동 요약만 읽습니다.
2. 활동에 출근/퇴근과 직접 입력한 체크인·회고를 연결합니다.
3. 원본 일기와 위치를 포함할 수 있는 메모는 비공개 개인 보관함에 저장합니다.
4. 주 1회 같은 코스의 시간·체감·날씨·교통 패턴을 요약합니다.
5. 공유를 선택하면 주간 집계 카드만 만들고 원본 기록은 내보내지 않습니다.

## 개인정보와 공유

- 집과 직장, 출발·도착 지점, 정확한 지도와 원본 좌표는 기본 비공개입니다.
- 위험했던 위치, 통증, 스트레스, 기분, 자유 일기는 개인 기록에만 둡니다.
- 공유 카드는 자출 일수, 총 거리, 출근/퇴근 비율, 평균 체감, 좋았던 순간처럼 집계·요약된 항목만 사용합니다.
- 탄소·비용 절감치를 넣는다면 대체 이동수단과 계산 가정을 밝히고 항상 `추정`으로 표시합니다.
- 주간 비교는 반복되는 관계를 발견하는 데 쓰며 원인을 증명하는 분석으로 표현하지 않습니다.

## 예시 출력

비공개 주간 회고:

```txt
이번 주 자출 6회 · 84 km
화·목 퇴근길은 비슷한 코스였지만 강한 맞바람과 높은 피로가 함께 기록되었습니다.
금요일 아침은 수면 점수는 낮았지만 교통이 한산해 체감이 가장 편안했습니다.
다음 주에는 목요일 저녁을 회복 이동이나 대중교통으로 바꾸고 앞 브레이크를 점검합니다.
```

공유용 집계 카드:

```txt
이번 주 자전거 출퇴근 6회 · 84 km
가장 편안했던 순간: 한산한 금요일 아침
집·직장·정확한 경로·건강 메모는 숨겼습니다.
```

## 검토 체크리스트

- [x] 본인 활동에만 접근합니다.
- [x] `activities:read`만 사용합니다.
- [x] 집·직장과 정확한 경로는 기본 비공개입니다.
- [x] 건강·안전 메모는 공유 결과에서 제외합니다.
- [x] 공유 결과는 주간 집계로 제한합니다.
- [x] 휴식과 대중교통 이용을 실패로 표현하지 않습니다.
