# Recipe: 자전거 출퇴근 일기

영문 문서는 [commute-diary-en.md](commute-diary-en.md)를 참고하세요.

## 목적

최근 자전거 출퇴근을 거리와 이동 시간 중심으로 정리하고, 이메일에 담긴 회고 질문에 직접 답하며 이동 경험을 돌아봅니다.

현재 Orider 결과는 최근 7일 자출 합계와 회고 질문을 본인 이메일로 보내는 비공개 리포트입니다. 아래의 체크인, 일기, 보관함, 공유 카드 흐름은 직접 구현할 수 있는 확장안이며 현재 제품 기능이 아닙니다.

이 레시피는 이동 경험을 돌아보는 개인 기록 도구입니다. 건강 상태를 진단하거나 사고 예방을 보장하지 않으며, 숫자가 라이더의 느낌보다 더 정확하다고 가정하지 않습니다.

## 직접 만드는 확장판에 필요한 scope

- `activities:read`: 본인의 날짜, 시간, 거리, 이동/경과 시간, 속도, 상승고도 같은 활동 요약을 읽습니다.

정확한 경로 좌표는 필요하지 않으므로 `streams:read`를 요청하지 않습니다.

현재 Creator Hub 이메일은 로그인한 라이더의 Orider 활동을 서버에서 읽으며 Personal Data API key를 요구하지 않습니다.

## 현재 제공 범위

- 요청 시점을 기준으로 최근 7일을 매번 새로 계산합니다.
- Strava의 출퇴근 표시가 있거나 활동명에서 출퇴근임이 명확한 활동을 후보로 사용합니다.
- 거리와 이동 시간을 기본 집계로 보여주며, 주행을 비교할 때는 거리와 이동 시간이 비슷한 활동을 기준으로 삼습니다.
- 몸 상태, 날씨, 교통 상황을 활동 데이터에서 추정하거나 저장하지 않습니다.
- 회고 질문은 Orider가 작성 템플릿으로 제공합니다. Orider가 현재 제공하는 결과는 합계와 질문을 본인 계정 이메일로 보내는 것까지이며 답변은 입력하거나 저장하지 않습니다.
- 체크인 입력 화면, 일기 보관함, 공유 카드는 아래 설명을 참고해 직접 구현해야 합니다.
- 이메일의 자출 횟수가 예상과 다르면 Strava 출퇴근 표시나 활동명을 수정한 뒤 다시 요청합니다. 현재는 발송 전에 후보를 고르는 화면을 제공하지 않습니다.
- 후보 활동이 없으면 `최근 7일 자출 없음`을 알리고 임의의 활동을 대신 넣지 않습니다. 거리나 이동 시간이 0인 활동은 비교 기준선에서 제외하며, 합계는 저장된 활동 요약값을 기준으로 표시합니다.

## 직접 만드는 확장판

아래 기록 흐름과 개인 보관함은 Personal Data API를 이용해 직접 만드는 기능입니다. 확장판에서는 라이더가 입력한 코스 별칭을 저장할 수 있지만, Orider가 경로를 판별하거나 코스 이름을 자동 생성한다고 가정하지 않습니다.

### 출발 전 약 1분

- 출근/퇴근, 자전거, 사용자가 입력한 코스 별칭 또는 우회 예정
- 수면·회복, 에너지, 기분, 스트레스: 간단한 5점 척도
- 통증이나 불편감: 선택 입력
- 라이더가 확인한 날씨와 예상되는 도로 위험
- 헬멧·타이어·브레이크·체인·라이트 빠른 확인

### 도착 후 약 2분

- 자동 기록: 날짜, 출발·도착 시각, 거리, 이동/경과/정차 시간, 속도, 상승고도
- 선택 지표: 평균 심박, 파워, 케이던스처럼 이미 활동 요약에 포함된 값
- 체감 안전도: `1 매우 불안`부터 `5 매우 안전`까지 기록
- 실제 피로·호흡·통증·집중도와 도착 후 기분
- 교통 상황, 우회, 아차 사고나 장비 문제
- 오늘 잘한 한 가지, 다음 이동에서 바꿀 한 가지, 기억하고 싶은 한 장면

### 주간 회고

- 자출 일수와 총 거리, 출근/퇴근 비율
- 거리와 이동 시간이 비슷한 주행의 이동 시간과 라이더가 기록한 상태 변화
- 낮은 체감 안전도나 높은 피로와 함께 반복된 조건 및 개인 메모
- 점검이나 정비가 필요한 항목과 가장 편안했던 조건
- 다음 주에 유지할 점과 바꿀 점

휴식이나 대중교통 이용은 끊긴 연속 기록이나 실패로 표시하지 않고 회복 또는 이동 선택으로 남깁니다.

## 데이터 흐름

현재 Orider 흐름:

1. Orider에 저장된 본인의 최근 7일 활동 요약만 읽습니다.
2. 출퇴근 표시 또는 명확한 활동명으로 후보를 고릅니다. 현재는 발송 전 후보 확인 화면을 제공하지 않습니다.
3. 자출 횟수, 총 거리, 총 이동 시간, 상승고도와 직접 답할 회고 질문을 본인 이메일로 보냅니다.

직접 만드는 확장판:

1. 출근/퇴근과 직접 입력한 체크인·회고를 활동에 연결합니다.
2. 원본 일기와 위치를 포함할 수 있는 메모를 비공개 개인 보관함에 저장합니다.
3. 주 1회 거리와 이동 시간이 비슷한 주행의 기록을 묶어 돌아봅니다.
4. 공유를 선택하면 주간 집계 카드만 만들고 원본 기록은 내보내지 않습니다.

## 개인정보와 공유

- 현재 Orider 결과는 본인 이메일로만 전송하며 공유 카드를 만들지 않습니다.
- 확장판에서 공유 기능을 만들더라도 공유 범위는 자출 일수, 총 거리, 총 이동 시간 같은 주간 집계로 제한합니다.
- 자유 문구, 집과 직장, 출발·도착 지점, 정확한 지도, 원본 좌표, 위험 위치, 건강·기분 메모는 공유에서 기본 제외합니다.
- 집계 문구에도 장소, 요일, 시각, 반복 일정이 집이나 직장을 추정할 단서로 남지 않았는지 보내기 전에 확인합니다.
- 탄소·비용 절감치를 넣는다면 대체 이동수단과 계산 가정을 밝히고 항상 `추정`으로 표시합니다.
- 주간 비교는 함께 나타나는 경향을 살피는 데 쓰며 원인을 증명하는 분석으로 표현하지 않습니다.

## 예시 출력

현재 제공하는 본인 이메일(주요 고정 항목을 보여주는 축약 예시):

```txt
최근 7일 요약
- 자전거 출퇴근 6회
- 합계 84 km · 4시간 12분 · 상승 620 m
- 거리와 이동 시간이 비슷한 주행 4회를 비교 기준선으로 표시했습니다.

Orider 고정 질문 · 매일 짧게 채우기
- 출발 전 몸 상태 (1 매우 좋지 않음–5 매우 좋음): ____
- 도착 후 피로 (1 낮음–5 매우 높음): ____
- 체감 안전도 (1 매우 불안–5 매우 안전): ____
- 날씨·노면: ____
- 교통·정차: ____
- 오늘의 한 줄: ____

7일 회고
- 거리와 이동 시간이 비슷한 주행에서 편해진 점과 불편했던 점은?
- 다음 7일 동안 유지할 한 가지와 바꿔 볼 한 가지는?

이 메일에는 몸 상태·날씨·교통 추정이나 일기 원문이 포함되지 않습니다.
```

직접 만드는 확장판의 주간 집계 카드:

```txt
최근 7일 자전거 출퇴근 6회 · 84 km · 이동 4시간 12분
집·직장·정확한 경로·요일·시각·자유 문구는 제외했습니다.
```
