# Strava 활동 지표 표시 재점검

전체 활동의 기본 기록은 `stravaRecordOf(activity)`가 반환하는 제공자 원본을 사용한다. 숫자가 다르다는 이유만으로 원본을 Orider 계산값으로 교체하지 않는다. 원본 필드가 없으면 결측으로 표시한다.

| 지표 | 기본 기록 | Orider 분석 |
| --- | --- | --- |
| 거리·평균/최고 속도 | distance, average_speed, max_speed | 거리 증거, 스트림 통계 및 평활 최고속도 |
| 이동·경과시간 | moving_time, elapsed_time | 스트림에서 판정한 이동·정지·관측시간 |
| 상승고도 | total_elevation_gain | 고도 보정 후 누적 상승 |
| 하강고도·고도 최고값 | 원본 요약에 없으면 결측 | 고도 스트림 계산, Orider 명시 |
| 평균/최고 파워·심박·케이던스 | 각 average_*, max_* 필드 | 선택 센서와 스트림의 집계 |
| 가중평균 파워 | weighted_average_watts | NP와 서로 다른 지표 |
| NP·TSS·IF·모델 에너지 | 원본으로 표시하지 않음 | Orider 분석 |
| 일량·칼로리·Relative Effort·기기 온도 | kilojoules, calories, suffer_score, average_temp | 자체 에너지/부하 모델, 날씨와 구분 |

후속 점검에서 고친 경로:

- 전체 차트: 원본 평균/최고 필드가 없을 때 스트림 계산값을 채우던 폴백 제거. 원본이 없는 최대 케이던스 등은 —.
- 개요: 원본 상승고도에 자체 계산 하강고도를 덧붙이던 표시 제거. 러닝 심박 부하·SWOLF도 원본 구역에 섞지 않음.
- 시간: Strava 이동시간을 기본 기록으로 유지. 정지 1분 미만이면 경과시간을 선택하던 공통 정책을 Strava에는 적용하지 않음. 원본이 없을 때 서버 시간으로 메우지 않음.
- 데스크톱/모바일 피드: 원본 스냅샷 우선. 평균속도를 표시 시간으로 재계산하지 않음. 누락 필드는 활동 문서의 다른 계산값으로 메우지 않음.
- 공유 카드: Orider NP/TSS가 없을 때 기존 가져오기 추정 TSS나 가중평균 파워를 대신 넣지 않음. 평균 파워 분석도 Orider로 명명.
- 차트 고도 최고값, 선택 구간 통계 및 가상 파워 미리보기는 Orider 분석으로 표시. 다른 센서의 원본 표시는 그대로 유지.
- 스트림이 없을 때의 센서 요약도 Strava 원본이라고 명시.
- 비교표: 시간·심박·케이던스·최고 파워·하강고도까지 출처를 함께 비교. 러닝 케이던스는 원본 보폭과 분석의 단위를 각각 확인한 뒤 spm으로 표시.

원본 수집·자동 요약 분리는 앞선 서버 변경에서 처리한다. Strava API가 제공하지 않는 Training Load/Intensity를 NP/TSS/IF로 추정해 원본처럼 만들지 않는다. 기존 누락 원본은 상세 재동기화가 필요하다. 이 후속 변경은 운영 데이터 백필이나 배포를 실행하지 않는다.
