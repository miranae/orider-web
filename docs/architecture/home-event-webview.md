# 홈 활동·소식 이벤트 상세 웹뷰

앱의 홈 이벤트 카드는 `/{lang}/embed/event/{eventId}`로 진입한다. `EventDetailSurface`가 일반
웹의 상세·등록·결과·주최자 관리 페이지를 공유하며 웹 전체 헤더·탭은 표시하지 않는다.
인증·테마·언어·재시도·계정 격리는 기존 `EmbeddedBootstrapRoot`의 계약을 따른다.
이벤트는 게스트 허브가 아니므로 앱 UID와 일치하는 세션을 승인한 뒤 내용을 표시한다.

이벤트 화면과 참가 취소·공개 참가자·프로필 조회는 주입된 Firebase 인스턴스를 사용한다.
같은 이벤트의 하위 경로는 같은 웹뷰 안에서 이동한다. CLUB_MEETING은 같은 이벤트 임베드 안의
`meeting/:groupId/:meetingId`에서 기존 ClubMeetingPage를 표시한다. 다른 대상은 기존 앱 브리지에
넘긴다. 네이티브 뒤로 가기는 상세를 닫고 유지된 홈으로 복귀한다.

배포 순서는 웹 라우트 운영 반영 후 앱 릴리스다. dev 머지만으로 운영 웹이나 스토어 앱이 바뀌지는
않는다. 앱 저장소의 같은 이름 작업 PR과 함께 검증하며, 새 경로가 운영에 반영되기 전 앱 릴리스를
진행하지 않는다.
