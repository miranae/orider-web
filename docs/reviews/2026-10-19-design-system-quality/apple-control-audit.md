# Apple HIG control-by-control audit — 2026-10-19

## Basis and verdict

Scope: the shared React catalogue and its activity-analysis consumers, not every legacy control in the repository. Read the current official HIG, inspect the shared implementation and inspect actual desktop/320/390px screens. Apple-native rendering is not available automatically in this React web implementation. Shapes, spacing, symbol choices and CSS material below are ORider web adaptations unless explicitly stated otherwise.

The previous description of Apple as flat/solid was too narrow. Gradients are neither universally required nor forbidden. HIG places greater weight on hierarchy, understandable actions, state and accessibility. A subtle CSS sheen is an ORider material choice, not a reproduction or certification of Liquid Glass. This audit does not establish a new ≥9.8 score.

## Material boundary

Use depth sparingly on the control/navigation layer. The content layer—tables, chart data, narrative and cards—is not converted into a translucent glass sheet. Power-zone sheen is local data-mark styling; its base hue and exact values remain the meaning. [Materials](https://developer.apple.com/design/human-interface-guidelines/materials)

Physical-device touch, full assistive-technology and 200% text-size acceptance are not established by these captures. These limits must not be converted to a high-score claim. For the 15px button labels, web text contrast is checked against WCAG 2.2 SC1.4.3's 4.5:1 normal-text threshold, including hover text and the composed sheen/pressed state. Native 44pt hit-region advice is not the source of this web contrast criterion. [W3C contrast minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

Final contrast correction and captures: both default/app-parity themes in light/dark, normal/hover/pressed are calculated above 4.5:1 after theme-relative control-only token corrections (lowest recorded 4.660:1; conservative sRGB clipping calculation). Final normal-state captures are `surface-buttons-final-light.jpg` and `surface-buttons-final-dark.jpg`. Full build and 14 targeted tests pass. The three chart/gauge/zone-label follow-ups above remain open; there is no final weighted-score acceptance.
