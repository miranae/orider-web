# 클럽 가상 모임 관전 — #1487

경로: `/:lang/club/:groupId/meetings/:meetingId/live`. 클럽·이벤트 상세 임베드 내부 경로도 지원한다. 모임 상세의 관전 링크에서 진입한다.

회원 전용 `getClubMeetingSpectator({eventId})`를 주입된 Firebase services로 Firestore 변경 신호를 구독해 회원 전용 조회를 직렬 실행한다. 위치 신호에는 본문 없이 갱신 시각만 들어 있으며, 모임/그룹/본인 회원 문서 변경도 재조회 트리거다. 계정/모임 전환, 숨김, 권한/조회 오류에는 코스·위치 상태를 지운다. 복귀 시 새 조회를 실행하며 이전 세대 응답은 버린다. 현재 응답에 포함된 참가자만 보존하고 개별 샘플이 역순이면 이전의 더 새로운 샘플을 사용하되 그 시각을 갱신하지 않는다.

코스 위 위치·선두/선택 선수 격차, 속도·만료된 파워·0W, 위치 수신 지연을 표시한다. 이름/ID 검색·팔로우 필터·지도/목록 선택·선수 추적·코스 전체 보기를 제공한다. 종료 시 실시간 위치 대신 모임 결과·그룹 기록으로 연결한다. 모임 결과 정리/활동 업로드가 끝났다는 주장은 하지 않는다.

공개 대회 EventLivePage의 조회·순위·배번·SOS를 변경하지 않았다. EventMap에는 기본값 false인 선택 선수 추적 옵션과 지도 CSS를 추가했다. 가상 위치를 게시하거나 실제 기록 거리·물리·ERG에 반영하는 경로는 없다.

## 시각 검증

`npm run dev -- --port 18487` 후 `/e2e/fixtures/club-spectator.html`을 연다. 합성 데이터 전용이며 Firebase 읽기/쓰기가 없다. `?lang=en`, `?state=finished`도 지원한다.

## 검증과 남은 수용

- 관전 관련 단위/컴포넌트·인증 경계와 기존 모임/임베드 내비게이션 회귀 검사.
- 타입 검사, lint:budget, quality:budget, build, 스크립트/배포 계약 검사. 빌드는 로컬 누락 AI API 환경값에 CI와 같은 placeholder를 사용한 컴파일 검증이며 운영 산출물로 배포하지 않는다.
- 서버 짝 PR의 emulator에서 주행자 2명+참가 문서 없는 관전 회원 및 탈퇴/삭제/종료 접근을 검증한다.
- 서버 문서에 조회 예산과 로컬 투영 p50/p95를 기록한다. 운영 종단간 지연·실제 청구 비용·다중 관전자 부하·실제 트레이너 동시주행은 미검증이다. #1487은 이 수용 항목까지 완료됐다고 닫지 않는다.

배포 순서: 서버 API → 실제 조회/권한 확인 → 웹. 이번 작업에서 운영 배포나 앱 출시는 수행하지 않는다.

재검토: P11 원칙에 따라 최초 10초 폴링을 제거했다. 구독 신호는 조회 트리거일 뿐 응답 내용을 덮어쓰지 않는다. 신호 권한 오류는 즉시 표시 데이터를 지우고 모든 구독을 해제한다.

연속 위치 신호는 5초 창에서 합쳐 한 번 조회한다. 신호가 없으면 타이머가 새 요청을 만들지 않으며 연속 신호가 마지막 타이머를 계속 미뤄 갱신을 굶기지 않는다. 요청이 진행 중이면 다음 재조회를 예약하고 병렬 호출하지 않는다.

격차와 진행순은 서버가 한 스냅샷에서 결정한다(P6). 선택 선수 ID는 조회 인자로 보내고, 응답 selectedUid가 현재 선택과 다르면 선택 격차는 비워 둔다. 기준 선수/본인 위치의 만료 시각도 서버가 내려주며 화면은 만료 시 값을 숨기는 역할만 한다.
