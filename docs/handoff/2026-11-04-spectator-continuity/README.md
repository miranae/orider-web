# 관전 사용자 동선 재검증

기준: 친구를 한 번 찾은 뒤에는 다른 앱·화면을 다녀와도 다시 찾지 않고 계속 관전할 수 있다.

검증한 범위:
- 친구 검색 → 선택 → 팔로우 필터 → 새로고침 후 선택·검색·필터 복원.
- 코스 전체 보기 ↔ 친구 따라보기 전환 및 지도 팝업 닫기에도 관전 대상 유지.
- 탭 숨김 시 위치 제거 → 복귀 시 회원 API 재검증 → 같은 친구로 재개.
- 재진입 때 회원 확인 실패 시 설정만 복원하고 위치는 표시하지 않음.
- 계정·모임별 설정 격리. 위치·코스·파워 본문을 저장하지 않음.
- 출발 전 친구 선택 후 위치 수신 시 재선택 없이 따라보기.
- 일시 장애의 제한된 자동 복구, 권한 오류 즉시 차단, 주기 조회 없음.
- 종료 결과 앵커와 취소 안내 분리.

`src/features/club-spectator/*.test.tsx`에서 저장·수명주기·권한 경계와 화면 동작을 검증한다. 서버의 `club-meeting-virtual.integration.test.ts`는 Firestore 에뮬레이터에서 대기 참석자 명단, 권한/삭제 제외, 신호 문서의 메타데이터 전용 계약, 코스 준비 전 대기를 검증한다.

스크린샷은 `/e2e/fixtures/club-spectator.html`의 합성 계정·코스만 사용했다. 실제 EventMap을 렌더링하되 배경 지도 스타일 요청만 결정적 빈 배경으로 대체했다. 모바일 390×844, 태블릿 834×1194, 데스크톱 1440×1100에서 위 검색·선택·필터·새로고침·카메라 전환 동선을 실행했으며 가로 넘침이 없었다.

실사용자 관찰, 실제 지도 타일 품질, 배포된 API, 앱 WebView 복귀, BLE 장비·다수 사용자 부하 검증을 대신하지 않는다. 운영 배포와 #1487의 운영 수용 조건은 별도 확인이 필요하다.
