9. Strava·연결 앱

이 장에서 할 수 있는 것

  • Strava를 연결해 새 활동을 자동으로 받고, 과거 활동을 한 번에 가져옵니다.
  • 활동을 Strava에 자동으로 올리고, Strava 활동 설명에 오라이더 요약을 자동으로 게시합니다.
  • Apple Health · Health Connect 같은 헬스 데이터 소스의 상태와 보존 기간을 확인합니다.
  • 연결을 끊거나, 가져온 기록이 제대로 들어왔는지 점검합니다.

9.1 Strava 연결하기

따라 하기

  1. 오른쪽 위 아바타 > 설정 > 왼쪽 연결 앱을 엽니다. (휴대폰 화면은 아바타 > 설정으로 들어간 뒤, 왼쪽 위 화살표로 설정 카테고리를 열고 연결 앱을 고릅니다.)
  2. 활동 앱 연결 카드의 Strava 줄에서 연결을 누릅니다.
  3. Strava 화면에서 오라이더의 접근을 승인합니다.
  4. 오라이더로 돌아오면 Strava 줄에 연결 해제 버튼이 보이고, 카드 오른쪽 위 숫자가 "1개 연결됨"으로 바뀝니다.
Garmin Connect · Wahoo SYSTM 같은 다른 활동 앱은 준비 중인 활동 앱을 펼치면 보이며, 아직 연결할 수 없습니다. 앱과 웹의 Strava 연결 상태는 서로 맞춰집니다.

Strava 로그인과 활동 연결은 별개입니다

로그인 창의 Strava로 계속하기나 설정 > 계정 > 로그인 연결의 Strava는 로그인용(공개 프로필 읽기 권한)입니다. 활동을 가져오려면 여기 연결 앱에서 따로 연결해야 합니다(10.1 로그인 연결). Strava로 처음 가입하면 연결 앱 화면 위에 운동기록 가져오기 카드가 나타나며, 운동 기록 연동하기로 활동 권한을 승인한 뒤 기록 가져오기로 이어집니다. 나중에를 눌러 건너뛸 수도 있습니다.

9.2 과거 활동 가져오기

  1. Strava를 연결하면 연결 앱 화면에 Strava 동기화 옵션 카드가 나타납니다.
  2. 과거 활동 가져오기 줄의 가져오기를 누르면 설정 > 내 데이터의 과거 활동 가져오기 카드로 갑니다. 거기서 다시 가져오기를 누릅니다(10.7).
  3. 진행 화면에서 가져온 활동 수와 진행 상황을 봅니다.
  4. 한 번 끝나면 같은 버튼이 리포트 보기로 바뀌어 결과를 다시 볼 수 있습니다.
과거 활동이 많으면 시간이 걸립니다. 가져온 활동은 분석·컨디션 계산이 끝난 뒤 차례로 채워집니다. 처음에 "가져온 기록을 분석하고 있어요"가 보여도 정상입니다.

9.3 자동 업로드

Strava 동기화 옵션 카드의 자동 업로드를 켜면 활동이 끝날 때 Strava에 자동으로 올라갑니다. 저장 · 동기화 · 업로드는 서로 다른 단계이므로, 결과는 앱과 Strava에서 직접 확인하세요.

같은 카드의 Strava용 요약 자동 생성 및 게시를 켜면, 앞으로 시작하는 활동이 Strava에 연결될 때 오라이더가 Strava용 요약을 만들어 Strava 활동 설명에 게시합니다. 기존 설명은 그대로 두고 오라이더 요약만 추가·갱신하며, 상세 AI 분석은 실행하지 않습니다. 설정을 불러오지 못하면 자동 게시 설정 다시 불러오기를 누릅니다.

휴대폰 앱이 Strava 업로드에 쓸 네트워크(모든 네트워크 · Wi-Fi만 · 오프라인)는 설정 > 기기의 네트워크 카드에서 봅니다(10.2).

9.4 연결 해제

  1. 설정 > 연결 앱 > Strava 줄의 연결 해제를 누르고 확인합니다. 이때 Strava 활동 동기화와, 연결돼 있다면 Strava 로그인도 함께 해제됩니다.
  2. 이미 가져온 활동은 그대로 남습니다. 이후 새 Strava 활동은 들어오지 않습니다.
Strava가 이 계정의 마지막 로그인 방법이면 해제되지 않습니다. 설정 > 계정 > 로그인 연결에서 Google · 네이버 · 카카오 · 디스코드 중 하나를 먼저 연결하세요(10.1).
Strava에서 가져온 활동까지 지우려면 설정 > 내 데이터의 Strava 활동과 상세 기록 삭제를 씁니다. 되돌릴 수 없습니다(10.7). Strava 쪽에 이미 올라간 데이터는 Strava에서 따로 지워야 합니다.

9.5 헬스 데이터 소스

연결 앱 화면 아래 헬스 데이터 소스에서는 워치·앱의 운동 · 수면 · HRV 데이터 연결 상태를 봅니다. 소스가 많을수록 회복·추세 분석이 정확해집니다.

소스연결 방법상태 표시
Strava위 활동 앱 연결에서 관리활성 · 허용된 스코프
Apple HealthiPhone 앱에서 권한을 줍니다.활성 · 마지막 동기화 시각
Health Connect화면에 항목은 있지만, 지금 출시된 Android 앱에서는 아직 연결할 수 없습니다.미연결

상태 표시는 활성 · 재인증 필요 · 해제됨 · 오류 · 미연결 중 하나입니다.

활성 소스가 두 개 이상이면 종목별 주 소스 카드가 나타납니다. 같은 운동이 여러 소스에 있을 때 피드에 보여 줄 소스를 종목(사이클 · 러닝 · 수영 · 기타)마다 고릅니다. "자동"은 가장 먼저 연결된 소스를 씁니다.

맨 아래 데이터 보존 카드: 원본 헬스 데이터는 기본으로 365일 보관한 뒤 자동 삭제되고, 일별 집계는 계속 남습니다. 원본 헬스 데이터 영구 보존을 켜면 원본도 기한 없이 남습니다. 다시 끄면 365일 규칙이 돌아오며, 이미 365일이 지난 원본은 다음 정리 때 지워집니다.

9.6 가져온 러닝 기록 점검하기

  1. 가져오기 리포트에서 완료 · 건너뜀 · 오류 수를 확인합니다.
  2. 홈에서 러닝 칩과 본인을 골라 활동을 찾습니다.
  3. 상세에서 종목 · 거리 · 시간 · 페이스를 보고, 랩 정보가 있으면 구간 탭의 랩 분석을 봅니다.

원본에 심박·케이던스·자세한 경로가 없으면 연결 뒤에도 생기지 않습니다. 같은 운동이 앱 · Strava · 파일로 각각 들어왔다면 출처를 확인하고 같은 파일을 또 올리지 마세요.

9.7 자주 막히는 점

이럴 때확인할 것
연결했는데 "0개 연결됨"으로 보여요화면을 새로 고친 뒤 다시 확인하세요. 계속 그렇게 보이면 게시판 문의/신고로 알려 주세요(11.5).
새 Strava 활동이 안 들어와요Strava 쪽 승인을 취소하지 않았는지, 활동이 Strava에 올라갔는지
같은 운동이 두 번 보여요종목별 주 소스를 정하세요(활성 소스가 두 개 이상일 때 보입니다). 훈련 부하는 같은 운동을 한 번만 셉니다.
Strava로 로그인했는데 활동이 안 들어와요Strava 로그인과 활동 연결은 별개입니다. 설정 > 연결 앱에서 Strava를 연결하세요(9.1).
"이미 활동 연동에 사용 중인 Strava 계정입니다"가 떠요그 Strava 계정은 다른 로그인 방법으로 만든 계정에서 이미 활동 연결에 쓰고 있습니다. 원래 로그인 방법으로 로그인한 뒤 설정 > 계정 > 로그인 연결에서 Strava를 연결하세요.
연결 해제가 안 돼요Strava가 마지막 로그인 방법이면 해제할 수 없습니다. 다른 로그인 방법을 먼저 연결하세요(9.4).
