10.1 계정 — 프로필 · 공개 범위 · 로그인 연결 · 동의

프로필

항목방법
이름이름 옆 변경을 누릅니다(2~30자). 피드·순위표·댓글 등 모든 곳에 반영됩니다.
친구 코드코드 복사로 복사해 친구에게 보냅니다(5.7).
사진사진 변경으로 올리고, 사진 삭제로 지웁니다.

신체 정보키와 체중. 체중은 W/kg 계산과 가상 파워에 쓰입니다. 자전거 프로필이 있으면 체중을 저장할 때 가상 파워에도 반영할지 묻습니다.

공개 범위 — 따라 하기

  1. 공개 범위 카드의 새 활동의 기본값에서 모두에게 공개 · 친구에게만 · 비공개 중 하나를 고릅니다. 한 번도 고르지 않았다면 비공개(나만 보기)입니다.
  2. 지금까지의 활동도 같은 범위로 바꾸려면 기존 활동에도 적용을 누릅니다. 대상 건수를 먼저 보여 주고 확인을 받습니다.
  3. 아래 스위치로 공개 프로필(다른 라이더가 검색하고 볼 수 있음, 기본 켜짐), 리더보드 참여(세그먼트 순위표에 내 기록 표시), 친구 요청 허용을 정합니다.

공개 범위 이름 대응표

공개 범위는 화면마다 이름이 조금씩 다르지만 모두 같은 3단계입니다.

단계화면에 보이는 이름누가 보나
전체 공개모두에게 공개 · 전체 공개 · 전체 · 전체공개모든 사용자 (세그먼트 순위표에도 들어갈 수 있음)
친구친구에게만 · 친구 · 팔로워만 · 친구만친구로 맺은 사람만 ('팔로워만'도 친구 공개와 같습니다)
비공개비공개나만

이름이 쓰인 곳: 웹 설정 > 계정 "모두에게 공개/친구에게만/비공개", 웹 활동 편집 "전체 공개/팔로워만/비공개", 웹 활동 ⋯ 메뉴 "전체 공개/친구/비공개", 웹 업로드 창 "전체/친구/비공개", 앱 "전체공개/친구만/비공개"

공개 범위는 활동마다 하나로, 누가 그 활동을 볼 수 있는지를 정합니다. 특정 활동만 다르게 하려면 그 활동의 ⋯ 메뉴나 활동 편집에서 바꿉니다(3.8). 활동을 볼 수 있는 사람에게 심박·파워 같은 항목을 보여 줄지는 아래 공개 데이터에서 계정 단위로 정합니다.
기존 활동에도 적용은 활동마다 따로 정해 둔 공개 범위까지 모두 바꿉니다.

공개 데이터 — 다른 사람에게 보여 줄 항목

공개 데이터 카드에서 내 활동을 볼 수 있는 사람에게 공개할 항목을 스위치로 고릅니다. 끄면 기존 활동에도 적용됩니다. 나에게는 그대로 보입니다.

항목처음 상태
심박 · 파워 · 훈련 지표 (TSS·IF) · 케이던스 · 칼로리켜짐(공개)
내 기준값 (FTP·최대 심박 설정·LTHR)꺼짐(비공개) — 직접 켤 때만 공개

알림 설정

알림 설정 카드에서 일반 푸시 알림, 좋아요 푸시, 댓글·답글 푸시, 주간 활동 요약 이메일을 켜고 끕니다. 일반 푸시가 꺼져 있으면 좋아요·댓글 푸시는 바꿀 수 없습니다. 긴급 알림과 일부 클럽·대회 알림은 이 스위치와 별도입니다. 푸시를 꺼도 받은 알림 목록은 남고, 브라우저 알림 권한은 바뀌지 않습니다. 주간 요약 이메일은 처음에 꺼져 있으며 직접 켤 때만 계정 이메일로 보냅니다.

로그인 연결 — 여러 로그인 방법을 한 계정에

로그인 연결 카드에서 Google · 네이버 · 카카오 · Strava · 디스코드 로그인을 지금 계정에 연결합니다. 연결해 두면 다음부터 그 서비스로 로그인해도 같은 계정(같은 프로필·활동)으로 들어옵니다.

  1. 지금 쓰는 계정으로 로그인한 상태에서 설정 > 계정 > 로그인 연결을 엽니다.
  2. 연결할 서비스 줄의 연결을 누르고, 그 서비스에서 로그인·인증합니다.
  3. 그 서비스로 이미 따로 만들어진 빈 계정이 있으면 "기존 O-Rider 계정에 연결할까요?"가 뜹니다. 현재 계정에 연결하기를 누르면(서비스에 따라 한 번 더 인증합니다) 그 별도 계정은 닫히고, 다음부터 그 서비스로 로그인해도 지금 계정으로 들어옵니다.
  4. 연결된 줄에는 "연결됨"과 해제 버튼이 보입니다.
따로 만든 계정에 기록이나 연결된 서비스가 있으면 자동으로 합치지 않습니다. 이때는 원래 로그인 방법으로 쓰고, 계정 통합은 고객지원에 문의하세요. 마지막 로그인 수단은 해제할 수 없습니다 — 해제 전에 다른 로그인 방법을 하나 더 연결해 두세요.
로그인 연결의 Strava는 로그인용(공개 프로필 읽기 권한)이고, 활동 가져오기·자동 업로드는 설정 > 연결 앱의 Strava 연결이 따로 맡습니다(9.1). 활동 동기화가 연결된 상태에서는 로그인 연결의 Strava를 바로 해제할 수 없으니, 다른 로그인 방법을 확보한 뒤 연결 앱에서 먼저 해제하세요.

그 밖의 카드

  • 의료·긴급 연락처 (선택) — 펼치면 혈액형, 복용약, 알레르기와 긴급 연락처를 관리합니다. 응급 시 구조대에 공유될 수 있습니다.
  • AI 코치 데이터 처리 — AI 코치가 답을 만들 때 필요한 개인 운동 데이터를 외부 AI 처리자에게 보내는 데 대한 동의 상태(동의함 · 동의 안 함 · 재동의 필요 · 철회됨). 안내 확인 및 동의로 동의하고 동의 철회로 거둡니다. 철회해도 저장된 대화는 남으며, 대화 내역 관리로 코치 > 대화에 가서 직접 지울 수 있습니다.
  • 계정 관리 — 로그아웃, 내 데이터 관리의 데이터 관리(10.7로 이동), 계정 및 데이터 삭제의 계정 삭제 안내 및 요청(10.8)

10.2 기기 — 휴대폰 앱 설정을 웹에서

  1. 설정 > 기기를 엽니다. 맨 위 설정할 기기에서 기기(예: 휴대폰 모델명)를 고릅니다. 마지막 동기화 시각과 기기 수("총 N개 기기")가 보입니다.
  2. 카드마다 편집을 눌러 값을 바꾸고 저장합니다. 카드 제목 옆 모든 기기는 내 모든 기기에 적용할 수 있는 설정(저장할 때 내 모든 디바이스에 적용을 고를 수 있음), 선택한 기기는 지금 고른 기기에만 적용되는 설정, 적용 범위 선택은 둘이 섞인 카드입니다.
카드내용
라이더 임계값FTP, 최대 심박, 체중 — 앱에 들어간 값. 기준이 되는 값은 설정 > 운동 프로필에서 관리합니다(10.9). 카드 아래 링크 문구는 "정본 기준값은 코치 > 컨디션에서 관리하세요"이지만, 누르면 설정 > 운동 프로필이 열립니다.
자동 일시정지 / 자동 랩멈췄다고 볼 속도·시간, 자동 랩 방식(거리·시간·끔)
알림 임계치심박 · 파워 · 케이던스 · 속도 범위를 벗어나면 앱이 알려 줄지
화면 / 사운드화면 밝기, 화면 자동 꺼짐, 동적 줌 · 헤딩 고정, 지도 유형, 사운드와 음량
배터리 / GPS배터리 절약, GPS 모드
네트워크지도 타일 · 날씨 · 위치 공유 · Strava 업로드가 쓸 네트워크(모든 네트워크 · Wi-Fi만 · 오프라인)
센서 페어링앱에 저장된 스피드 · 케이던스 · 심박 · 파워 · 레이더 · 변속기 · 액션캠 센서. 보기만 할 수 있으며, 페어링은 휴대폰 앱 > 설정 > 센서에서 합니다.

자전거별 설정 · 데이터 페이지 · 가상 파워

같은 화면 아래쪽에서 자전거 프로필을 골라 자전거마다 따로 저장되는 값을 관리합니다.

영역내용
자전거 프로필휠 둘레, 연결된 센서, 가상 파워 사용 여부. 활성이 아닌 자전거는 활성으로를 눌러 바꿉니다.
데이터 페이지앱 기록 화면의 페이지와 칸 배치를 자전거마다 편집합니다. 다른 기기에서 먼저 저장했다면 무엇을 남길지 고르라고 묻습니다.
기기에 남은 옛 데이터 페이지예전에 기기 단위로 저장한 구성입니다. 보기만 할 수 있고, 이 구성을 자전거로 가져오기로 원하는 자전거에 옮길 수 있습니다.
가상 파워 (Virtual Power)파워미터 없이 속도·경사·체중·자전거 무게로 파워를 추정합니다. 활성 프로필에 적용되며, 자전거 무게 · 구름 저항(Crr) · 공기저항면적(CdA)을 정합니다. 라이더 체중은 계정의 신체 정보 값을 씁니다.
기존 활동 추정 파워 업데이트지난 라이딩에 가상 파워를 채웁니다. 누락된 추정 파워 계산(아직 없는 기록만) 또는 전체 재계산을 고르고 진행 상태를 봅니다.
동기화된 기기가 없으면 휴대폰 앱에서 설정을 한 번 바꾸면 여기 나타납니다. 이름 변경 · 휴지통(기기 설정 삭제) · 새로고침 버튼은 기기 선택 칸 오른쪽에 있습니다. 자전거 프로필이 없으면 앱에서 먼저 만들어야 합니다.

10.3 장비 — 자전거 프로필 · 바이크 킷 · 신발

아바타 > 장비에서 관리합니다.

영역내용
자전거 프로필앱에서 만든 자전거 목록과 누적 이동거리. "활성" 표시, 휠 둘레, 연결된 센서 수, 가상 파워 사용 여부. 연필로 이름을 바꾸고 휴지통으로 지웁니다. 마지막 1개는 지울 수 없습니다. 자전거가 많으면 처음 3대만 보이고 다른 자전거 프로필 N개로 펼칩니다. 자전거 줄의 기기를 누르면 그 자전거의 설정 > 기기 화면이 열립니다.
바이크 킷장비 추가로 바이크·휠·파워미터 등을 등록합니다. 코스 시뮬레이터가 이 장비의 물리 값을 씁니다.
최근 활동의 신발최근 8주 활동에 기록된 신발별 누적 이동거리와 남은 거리. 남은 거리가 15% 아래로 내려가면 "교체 임박"으로 표시합니다. 전체 신발 목록은 아닙니다.
가상 파워 설정과 지난 라이딩의 추정 파워 채우기는 설정 > 기기 화면 아래쪽에 있습니다(10.2). 자전거 프로필이 없으면 앱에서 먼저 만들어야 보입니다. 센서 페어링은 앱에서 합니다.

10.4 연결 앱

Strava 연결·해제, 자동 업로드, Strava용 요약 자동 게시, 과거 활동 가져오기, 헬스 데이터 소스, 종목별 주 소스, 헬스 데이터 보존은 9장을 보세요. Strava·네이버 같은 서비스로 로그인하는 연결은 설정 > 계정 > 로그인 연결에 따로 있습니다(10.1).

10.5 개발자 — 개인 데이터 API 키

내 오라이더 데이터를 개인 차트 · 알림 · 리포트 · 자동화(Notion, Slack, n8n 등)에 쓰는 읽기 전용 키입니다.

따라 하기

  1. 설정 > 개발자를 엽니다.
  2. 키 이름을 정합니다(예: Notion 주간 리포트, 개인 대시보드).
  3. 허용할 데이터에서 필요한 것만 고릅니다 — profile:read(프로필), activities:read(활동), streams:read(상세 기록), fitness:read(컨디션), exports:read(내보내기).
  4. 키 생성을 누르고, 바로 나오는 전체 키 값을 복사해 안전한 곳에 둡니다.
  5. 바로 실행해보기의 예시 명령으로 내 활동 목록이 읽히는지 확인합니다. 자세한 사용법은 개발자 문서의 API 문서·활용 예시에 있습니다.
새 키는 만든 직후 한 번만 전체 값을 보여 줍니다. 이후에는 앞부분만 보입니다. 브라우저 코드, 공개 저장소, 스크린샷에 키를 넣지 마세요. 필요 없어진 키는 내 API 키 목록에서 폐기합니다(되돌릴 수 없음).

앱 모양새 > 테마시스템 · 라이트 · 다크
디자인 테마기본 · 앱 스타일 — 색상 · 모서리 · 글꼴을 한 번에 바꾸며 바로 반영됩니다.
일일 기준 시간대는 오늘의 계획, 일별 집계 같은 하루 경계를 정합니다. 바꾸면 앞으로의 하루 경계만 바뀌고, 이미 만들어진 지난 기록은 다시 계산하지 않습니다.
테마를 시스템으로 두면 컴퓨터·휴대폰의 밝기 모드를 바꾸는 즉시 화면도 따라 바뀝니다. 이벤트·클럽 모임의 라이브 화면은 절전을 위해 다크 화면을 우선해서 보여 줍니다.

10.7 내 데이터 — 가져오기 · 내보내기 · 삭제

카드하는 일
과거 활동 가져오기Strava의 과거 활동을 한 번에 가져옵니다. Strava가 연결돼 있으면 가져오기(끝난 뒤에는 리포트 보기), 연결 전이면 연결 버튼이 보입니다(9.2).
데이터 내보내기전체 활동 다운로드 줄의 전체 데이터 다운로드 — 프로필·활동 JSON, 활동 목록 CSV, GPS 기록이 있는 활동의 GPX 등을 ZIP 파일로 받습니다. 진행률이 표시됩니다.
활동 데이터 삭제활동 상세 기록 삭제 줄의 상세 기록 삭제 — 서버에 저장된 모든 내 활동의 상세 기록(스트림)을 지웁니다. 활동 요약은 남지만 상세 차트·경로는 볼 수 없게 됩니다.
Strava 활동과 상세 기록 삭제 — Strava에서 가져온 활동을 삭제 처리하고, 출처와 관계없이 모든 활동의 서버 상세 기록을 지웁니다. Strava 가져오기 상태와 공유 요약도 초기화됩니다. 계정은 남습니다.
삭제는 되돌릴 수 없습니다. 먼저 전체 데이터 다운로드로 받아 두세요.

10.8 계정 및 데이터 삭제 요청

계정 자체를 없애려면 앱을 다시 설치하지 않아도 웹에서 요청할 수 있습니다. 휴대폰 앱과 Wear OS 워치에서 쓰는 같은 계정에 적용됩니다.

따라 하기

  1. 설정 > 계정 > 계정 관리의 계정 삭제 안내 및 요청을 누릅니다. (주소 orider.co.kr/account-deletion으로 바로 가도 됩니다.)
  2. 맨 위 안내(Apple 로그인·게스트 계정은 이메일로 요청)와 삭제 범위와 처리 안내를 끝까지 읽습니다. 필요한 기록은 먼저 내보내세요.
  3. 삭제할 계정으로 로그인돼 있는지 "삭제 대상 계정"을 확인합니다.
  4. 칸에 DELETE를 입력하고 계정 및 데이터 영구 삭제 요청을 누릅니다. 최근 로그인 확인이 필요하면 본인 인증 다시 하기 후 다시 누릅니다.
  5. 같은 화면에서 처리 상태(접수 → 삭제 중 → 완료)를 확인합니다.
요청 접수·로그아웃·화면 닫기는 삭제 완료가 아닙니다. 서버가 정리를 확인해야 "완료"로 표시됩니다. Strava 같은 외부 서비스에 이미 보낸 데이터는 그 서비스에서 따로 지워야 하며, 오라이더 삭제로 외부 계정까지 지워지지는 않습니다.
Apple 로그인·게스트 계정이거나 로그인할 수 없다면 삭제 화면에 안내된 개인정보 담당자 이메일로 요청합니다. 위임 로그인·워치 연결 세션에서는 요청할 수 없고, 원래 계정으로 본인 인증해야 합니다. 백업·제공업체 보관 기간 같은 자세한 내용은 삭제 화면과 개인정보처리방침을 보세요.

10.9 운동 프로필 — 훈련 기준값

설정 > 운동 프로필에서 FTP · 최대 심박 · LTHR · 역치 페이스 같은 운동 임계치와 종목별 심박 존을 입력하고 저장합니다. 체중은 계정의 신체 정보 값을 씁니다. 파워미터로 측정했다면 FTP 테스트에 평균 파워를 넣어 FTP 후보를 계산하고 적용한 뒤 저장합니다.

값의 뜻과 입력 요령은 6.5를 보세요. 화면 아래 기기 반영 상태 보기 →를 누르면 휴대폰 앱에 들어간 값을 설정 > 기기에서 확인할 수 있습니다(10.2).

예전 코치 > 컨디션 > 전체 종목 훈련 기준 설정으로 들어가는 링크는 이제 이 화면으로 열립니다.
