1. 웹 시작하기

이 섹션의 목적

오라이더 웹에 접속하여 자전거와 러닝 기록을 같은 계정에서 확인하고, 운동 후 분석·훈련 계획으로 이어가는 방법을 익힙니다. 앱에서 저장한 활동은 계정 동기화가 완료된 뒤 웹에서 확인합니다.

1.1 앱과 웹 — 역할이 다르다

오라이더 앱과 웹은 같은 데이터를 다루지만, 사용 시점과 목적이 완전히 다릅니다.

앱 (모바일)웹 (브라우저)
언제라이딩·러닝 중라이딩·러닝 이후
역할기록하는 도구분석하는 도구
핵심 질문"지금 속도·페이스가 얼마지?""이번 주에 얼마나 타고 달렸는가?"
화면스마트폰 (운동 중 필요한 정보)PC/태블릿 (큰 화면에서 분석)
앱에서 기록하고, 웹에서 분석한다 — 이 흐름을 기억하세요. 러닝의 기록 시작·일시정지·종료는 모바일 앱에서 진행하고, 웹에서 페이스·스플릿·심박을 되짚어 봅니다.

1.2 접속과 로그인

확인할 것

orider.co.kr에 접속하면 대시보드가 표시됩니다. 비로그인 상태에서는 다른 사용자의 전체 공개 활동이 피드에 보이고, 상단에는 "Google로 시작하기" 안내가 표시됩니다. 내 기록과 주간 통계는 로그인 후에 나타납니다.

해야 할 것

오른쪽 상단 "Google 로그인" 클릭
→
Google 계정 선택
→
대시보드에 내 데이터 표시

결과

로그인이 완료되면 앱에서 동기화된 자전거·러닝 활동을 대시보드에서 확인할 수 있습니다. 처음 로그인하면 프로필이 자동 생성됩니다.

반드시 앱과 같은 Google 계정으로 로그인해야 합니다. 다른 계정으로 로그인하면 빈 대시보드가 표시됩니다.

1.3 웹이 답하는 질문들

웹에서 무엇을 할 수 있는지를 메뉴 목록이 아니라, 라이딩·러닝 이후 자연스럽게 떠오르는 질문으로 이해하세요.

운동 후 궁금한 것웹에서 확인하는 곳이 매뉴얼
"이번 주에 얼마나 타고 달렸지?"대시보드 → 최근 7일 요약2장
"오늘 운동의 속도·페이스는 어땠지?"활동 상세 → 지도, 고도, 분석 탭3장
"이 오르막에서 나는 몇 등이지?"리더보드 → 세그먼트 순위4장
"친구와 그룹의 운동 기록은 어떻지?"그룹 → 대시보드5장
"내 체력이 올라가고 있는 건가?"피트니스 → 점수, 파워 커브6장

결과

처음에는 2장(기록 확인)과 3장(상세 분석)만으로 충분합니다. 데이터가 쌓이고 궁금한 것이 늘면 4~6장으로 자연스럽게 넘어갑니다.

1.4 첫 로그인 후 초기 설정 (온보딩)

Google 계정으로 처음 로그인하면 3단계 온보딩 화면이 초기 설정을 안내합니다. 상단 진행 막대로 현재 단계를 확인할 수 있습니다.

결과

모든 단계를 마치면 홈 화면으로 이동하고, 선택한 종목 기준으로 대시보드가 표시됩니다.

1.5 러닝을 처음 확인하는 순서

  1. 모바일 앱에서 러닝을 선택해 기록하고 저장합니다. Android 매뉴얼 또는 iOS 매뉴얼에서 기록 절차를 확인하세요.
  2. 웹에 같은 계정으로 로그인하고, 종목 선택에서 러닝을 고릅니다.
  3. 최근 활동을 열어 거리·시간·평균 페이스를 확인한 뒤 스플릿·심박·케이던스를 봅니다.
  4. 설정의 운동 프로필에 러닝 임계 페이스를 입력하고, 운동 계획에서 목표 거리와 날짜를 정합니다.
활동이 보이지 않으면 계정, 종목 필터, 검색 기간부터 확인하세요. 기록이 저장되지 않았거나 동기화 중이면 웹에 아직 표시되지 않을 수 있습니다.
