4. 화면과 소리 꾸미기

이 장에서 할 수 있는 것
  • 기록 화면에 보일 데이터 필드를 고르고, 페이지를 늘리거나 프리셋을 씁니다.
  • 지도 회전·야간 지도 같은 지도 설정을 바꿉니다.
  • 알림음과 심박·파워 수치 알림, 테마를 정합니다.

이 장의 설정은 모두 설정 > 화면(화면 제목 “주행/화면”)에서 시작합니다. 이 화면에는 주행 · 데이터 필드 · 네비게이션 · 사운드가 있습니다.

따라 하기: 데이터 필드 고르기

  1. 설정 > 화면 > 데이터 필드를 엽니다. iOS 설정 > 화면 > 디스플레이 > 필드 설정(0장 대응표).
  2. 맨 위에서 라이드 또는 러닝을 고릅니다. 두 배치는 따로 저장됩니다.
  3. 라이드라면 적용 자전거를 확인합니다. “데이터 페이지는 자전거마다 따로 저장됩니다.”
  4. 숫자 1 · 2 · 3으로 편집할 페이지를 고릅니다. 양옆 버튼으로 페이지를 추가하거나 삭제합니다.
  5. 빠르게 시작하려면 프리셋을 누르고, 직접 바꾸려면 아래 미리보기에서 칸을 눌러 필드를 고릅니다(“미리보기에서 위치를 탭하여 편집”).
  6. 맨 아래 (자전거 이름)에 저장 또는 러닝에 저장을 눌러야 반영됩니다.
종목한 페이지 프리셋여러 페이지 프리셋
라이드기본 · 간단 · 파워 중심 · 상세훈련(2페이지) · 트레이닝+(3페이지) · 투어링(3페이지)
러닝간단 · 페이스 · 인터벌 · 장거리러닝 훈련(2페이지) · 장거리 러닝(3페이지)

NP·IF·TSS 같은 용어는 부록 용어에 풀어 두었습니다. 센서가 없는 필드는 --로 표시됩니다.

지도 설정

Android 지도 설정은 설정 > 화면 > 네비게이션 화면 아래쪽 지도 구역에 있습니다. iOS iPhone은 설정 > 화면 > 디스플레이의 지도 구역입니다(0장 대응표).

항목설명
타일 엔진지도를 그리는 방식입니다. 보통은 처음 값 그대로 두면 됩니다.
오프라인 지역내비 경로 계산용 지역 파일. 6장 오프라인 지역을 보세요.
이동방향으로 회전내가 가는 방향이 늘 위쪽이 되도록 지도를 자동으로 돌립니다. 끄면 북쪽이 위입니다.
야간 지도 모드어두운 지도 스타일로 바꿔 화면 전력을 줄입니다.

지도 종류 이름은 플랫폼마다 다릅니다.

  • Android 지도 유형: 일반 · 자전거 도로 · 지형 · Mapbox
  • iOS 지도 스타일: 일반 · 위성 · 혼합 · 지형

알림음

설정 > 화면 > 사운드에서 정합니다. iOS 설정 > 화면 > 소리(0장 대응표).

항목설명
사운드 사용 · 볼륨전체 알림음 켜기와 크기
워크아웃 타겟 알림음워크아웃 목표 범위를 벗어날 때
오르막 알림음 · 세그먼트 알림음오르막·세그먼트 시작과 끝
커스텀 사운드시작 · 종료 · 랩 · 오르막 시작 · 오르막 종료 · 레이더 알림 소리를 각각 변경
레이더를 쓰면 레이더 알림 소리는 켜 두세요. 화면을 보지 않아도 뒤 차량을 알 수 있습니다.

수치 알림 (임계치 알림)

설정 > 주행 설정 > 임계치 알림에서 심박(bpm) · 파워(W) · 케이던스(rpm) · 속도(km/h)의 최소·최대값을 넣으면, 범위를 벗어날 때 알려 줍니다.

러닝 페이스(분/km)는 속도(km/h)와 단위가 다릅니다. 속도 알림에 페이스 숫자를 넣지 마세요.

테마

Android 설정 > 디자인 > 테마에서 기본 또는 고대비 (야외)를 고릅니다. 햇빛 아래에서 화면이 잘 안 보이면 고대비를 써 보세요. iOS iPhone에는 테마 설정이 없습니다.

자주 막히는 점

데이터 필드를 바꾸고 저장을 누르지 않고 나가면 반영되지 않습니다.
라이드 배치를 바꿨는데 기록 화면이 그대로라면, 기록하는 자전거(활성 자전거 프로필)가 편집한 적용 자전거와 같은지 확인하세요.
