10. 설정 한눈에

이 장에서 할 수 있는 것
  • 설정 메뉴 전체에서 원하는 항목이 어디 있는지 찾습니다.
  • 계정·공개 범위, 데이터 절약, 배터리 절약을 상황에 맞게 정합니다.
  • 언어·경량 모드·시뮬레이션 같은 고급 항목을 압니다.

설정은 더보기 > 설정에서 엽니다. 라이딩·러닝 준비 화면 오른쪽 위 톱니(라이딩 설정 / 러닝 설정)를 눌러도 열립니다.

FTP · 최대 심박은 웹 코치 > 훈련 상태 > 전체 종목 훈련 기준 설정과 앱 설정 > 주행 설정 > 라이더 프로필 어느 쪽에서 바꿔도 서버가 서로 맞춰 줍니다. 체중은 웹 훈련 기준 설정에서 바꾸세요(앱에서는 설정 > 내 자전거 > 가상 파워를 켰을 때 ‘라이더 체중’으로 보입니다). 가장 나중에 저장한 값이 양쪽에 적용되며, 반영까지 잠시 걸릴 수 있습니다. 분석·존·목표 판정은 웹의 훈련 기준 설정 값을 기준으로 계산하므로, 값이 다르게 보이면 웹 코치 > 훈련 상태에서 확인하세요.

계정 삭제와 데이터 내보내기

계정 삭제 요청과 전체 데이터 내려받기는 앱이 아니라 웹(orider.co.kr)에서 합니다.

  • 데이터 내보내기·기록 삭제 — 웹 설정 > 내 데이터. 웹 설명서 10.7을 보세요.
  • 계정 및 데이터 삭제 요청 — 웹 설정 > 계정 > 계정 관리의 “계정 삭제 안내 및 요청”, 또는 orider.co.kr/account-deletion. 절차는 웹 설명서 10.8을 보세요.
Apple 로그인·게스트 계정이거나 로그인할 수 없다면 삭제 화면에 안내된 개인정보 담당자 이메일로 요청합니다. 필요한 기록은 삭제 요청 전에 먼저 내보내세요.

시스템

데이터 절약

iOS iPhone은 설정 > 시스템 > 전력 관리에서 데이터 절약을 정하고, 선택지 이름은 오프라인 · 모두 허용 · Wi-Fi만입니다(0장 대응표). 아래 표는 Android 기준입니다.

Android 항목마다 오프라인 · 셀룰러+WiFi · WiFi만 중 하나를 고릅니다. 화면 맨 위에 현재 네트워크(예: WiFi)가 표시됩니다.

항목쓰는 곳오프라인으로 두면
지도 타일지도 이미지 다운로드이미 받아 둔 지도만 보입니다.
날씨 정보실시간 날씨 업데이트날씨가 갱신되지 않습니다.
위치 공유친구/그룹 실시간 위치친구·그룹이 내 위치를 받지 못합니다.
Strava 업로드라이딩 기록 업로드Strava에 올라가지 않습니다.

배터리 절약

iOS iPhone은 설정 > 시스템 > 배터리 설정입니다. 프리셋(표준 · 절약 · 대시보드 · 사용자 정의), GPS 모드(고정밀 · 균형 · GPS 끔), 화면 밝기가 있고, “화면 자동꺼짐” 대신 설정 > 화면 > 디스플레이 > 화면 켜짐 유지를 씁니다. 아래 그림과 표는 Android 기준입니다.

항목선택설명
프리셋표준 · 절약 · 대시보드 · 사용자 정의절약·대시보드를 고르면 위치 공유와 날씨 정보가 자동으로 꺼집니다. 항목을 직접 바꾸면 사용자 정의가 됩니다.
주행 생존 목표2h · 4h · 6h측정한 배터리 소모율로 이 시간만큼 버티지 못하면 절전을 자동으로 강화합니다.
GPS 모드고정밀 · 절전 · OFFOFF는 GPS를 끕니다. 지도·경로가 기록되지 않으니 실내 트레이너에서만 쓰세요.
화면 밝기시스템 · 80% · 50%라이딩 중 화면 밝기
화면 자동꺼짐항상 켜짐 · 시스템 기본거치대에 두면 항상 켜짐, 주머니에 넣으면 시스템 기본이 알맞습니다.

자주 막히는 점

장거리 라이딩 전에는 배터리 절약의 주행 생존 목표를 예상 시간에 맞추고, 보조 배터리를 챙기세요.
