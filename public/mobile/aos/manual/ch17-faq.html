17. 문제 해결 (FAQ)

라이딩 중 문제가 생기면 아래를 먼저 확인해 보세요.

센서가 검색되지 않아요

  • 센서를 깨워주세요 — 크랭크를 돌리거나, 심박 센서를 가슴에 착용하거나, 센서의 버튼을 눌러 절전 모드를 해제합니다
  • 블루투스가 켜져 있는지 확인하세요
  • 다른 앱(Garmin Connect 등)에서 해당 센서가 연결 중이면 먼저 해제하세요. BLE 센서는 동시에 하나의 앱에만 연결됩니다
  • 센서와의 거리가 너무 멀지 않은지 확인하세요 (BLE는 보통 10m 이내)

센서 연결이 자주 끊겨요

  • 센서 배터리를 교체해 보세요 — 가장 흔한 원인입니다
  • 폰 케이스가 금속 재질이면 BLE 신호를 차단할 수 있습니다
  • 여러 BLE 기기가 동시에 연결되어 있으면 간헐적 끊김이 발생할 수 있습니다

GPS 속도·러닝 페이스·거리가 부정확해요

  • 높은 건물 사이나 나무 밀집 지역에서는 GPS 정확도가 떨어질 수 있습니다
  • 배터리 절약 → GPS 모드가 "고정밀"인지 확인하세요 ("균형" 모드는 정확도가 낮음)
  • 보다 정확한 속도를 원하면 CSC 속도 센서를 연결하세요 — 바퀴 회전 기반이라 GPS보다 정확합니다
  • 앱 시작 직후에는 GPS 위성 수신에 몇 초 걸릴 수 있습니다. GPS 정확도 필드를 확인하여 10m 이내가 될 때까지 기다려 보세요

화면이 꺼지면 기록이 멈춰요

  • Android 설정에서 Orider 앱의 백그라운드 위치 권한이 "항상 허용"인지 확인하세요
  • 배터리 최적화에서 Orider를 제외하세요 (제조사별 설정이 다릅니다)
  • Samsung: 설정 → 배터리 → 백그라운드 사용 제한 → Orider 제외
  • Xiaomi: 설정 → 앱 → Orider → 배터리 절약 → 제한 없음
  • 배터리 절약 → 화면 자동꺼짐을 "항상 켜짐"으로 설정하는 것도 방법입니다

Strava 업로드가 안 돼요

  • 설정 → 계정에서 Strava 연결 상태를 확인하세요. "연결 해제" 후 다시 연결해 보세요
  • 데이터 절약 → Strava 업로드가 "오프라인"으로 되어 있지 않은지 확인하세요
  • 네트워크 연결을 확인하세요

ClimbPro가 작동하지 않아요

  • GPX 경로를 먼저 불러와야 합니다. 경로 없이는 오르막 감지가 불가능합니다
  • 경로에 오르막이 없거나 Cat 4 미만(점수 8,000 미만)의 짧은 경사는 감지되지 않습니다
  • 현재 위치가 경로와 너무 멀리 떨어져 있으면 오르막에 진입해도 감지되지 않을 수 있습니다

앱이 비정상 종료돼요

  • 설정 → 고급 → 크래시 로그에서 오류 내역을 확인할 수 있습니다
  • 앱을 최신 버전으로 업데이트해 주세요
  • 문제가 지속되면 크래시 로그를 개발자에게 공유해 주세요

러닝이 자전거로 저장됐어요

기록 시작 전 종목 선택을 확인하세요. 화면 배치만 바꾸거나 러닝 GPX를 불러오는 것으로 종목이 바뀌지는 않습니다. 기록 중에는 종목을 전환할 수 없습니다. 활동 상세와 Strava의 활동 유형을 함께 확인하고 다음 활동부터 러닝을 선택해 시작하세요.

러닝 페이스가 --:--이거나 흔들려요

정지 상태나 유효한 속도가 없는 경우 --:--은 정상입니다. 출발 직후·고층 건물·터널에서는 GPS 신호가 안정될 때까지 기다리세요. 페이스 6:00 /km는 1km당 6분이며, 자전거 속도 6km/h와 같은 값이 아닙니다. 짧은 순간값보다 평균 페이스와 거리·시간·트랙을 함께 확인하세요.

러닝 케이던스가 안 보여요

Android 설정 → 앱 → Orider → 권한에서 신체 활동 권한을 확인하세요. 걸음 감지 센서가 없는 기기는 케이던스를 제공하지 못할 수 있습니다. 폰을 몸에 지니고 몇 걸음 이동한 뒤 확인하세요. 러닝 케이던스의 단위는 spm입니다. 자전거 센서를 연결하거나 휠 둘레를 바꿔도 걸음 케이던스가 생기지 않습니다.

러닝을 선택하니 자전거 센서가 연결되지 않아요

러닝에서는 자전거 속도·케이던스·파워·변속기·레이더 센서에 연결하지 않는 것이 정상입니다. 러닝에 필요한 심박 센서를 확인하세요. 자전거를 다시 탈 때는 기록 시작 전에 자전거 종목을 선택합니다.

러닝 중 자동 일시정지가 자전거와 달라요

러닝은 1.0 km/h와 5초 지연을 사용하는 종목 기준으로 동작합니다. 자전거 자동 일시정지 속도 설정과 구분하세요. GPS 흔들림·낮은 속도·완전 정지 상태에서는 반응 시점이 달라질 수 있으므로 화면의 기록 상태를 확인하고 필요하면 수동 일시정지를 사용하세요.

음성 러닝 코칭 메뉴가 없어요

기본 러닝 기록은 종목 선택·시작·일시정지·종료 흐름으로 사용할 수 있습니다. 러닝30·오늘의 러닝 계획은 지원 버전에서 로그인과 서버 연결 상태에 따라 제공됩니다. 프로그램·계획 사용법을 확인하세요. 경로 안내나 시작·랩 알림음과도 구분하세요.
