자전거 · 러닝 활동 기록 앱 · Android

개정 2026-09-29 · 자전거 / 러닝

처음 사용자를 위한 빠른 시작

Orider를 처음 설치하셨나요? 아래 5단계만 따라하면 바로 자전거 라이딩이나 러닝을 시작할 수 있습니다.

1
앱 설치 후 권한 허용
GPS 기록을 위해 위치 권한을 허용하세요. 센서 사용 시 블루투스, 러닝 걸음 케이던스 사용 시 신체 활동 권한도 확인하세요. 백그라운드 위치도 허용하면 화면이 꺼져도 기록이 이어집니다.
2
센서 연결 (선택사항)
자전거 속도/케이던스 센서 또는 공용 심박 센서가 있다면 설정 → 센서에서 페어링합니다. 센서가 없어도 GPS로 자전거 속도·러닝 페이스와 거리를 기록할 수 있습니다.
3
데이터 화면 꾸미기 (선택사항)
설정 → 데이터 필드에서 화면에 표시할 데이터를 선택합니다. 기본 구성 그대로 사용해도 좋습니다.
4
종목 선택 후 시작
기록 전 메인 화면 상단에서 자전거 / 러닝을 고른 뒤 하단의 시작 버튼을 탭합니다. 기록 중에는 종목을 바꿀 수 없습니다. 좌우 스와이프로 데이터/지도 화면을 전환하세요.
5
활동 종료 후 기록 확인
일시정지 버튼을 탭하면 재개/정지 버튼이 나타납니다. 정지 버튼을 탭하면 활동이 종료되고, 거리·시간과 자전거 속도 또는 러닝 페이스 요약을 확인합니다. Strava 자동 업로드를 켰다면 업로드 상태와 Ride / Run 유형도 확인하세요.
더 자세한 내용은 아래 각 섹션에서 확인하세요. 센서 연결은 4. 센서 연결, 화면 꾸미기는 3.2 레이아웃 에디터를 참고하세요.
화면 이동 — 하단의 홈 · 피트니스 · 라이딩(또는 러닝) · 계획 · 더보기 탭으로 이동합니다. 활동 기록은 홈, 경로 보관함·센서·연결 서비스·설정은 더보기에서 찾습니다. 러너 홈에서 일반 러닝 또는 오늘의 계획을 시작할 수 있습니다.
종목별 읽는 법
자전거: 속도 km/h · 케이던스 rpm · 자전거 센서 지표
러닝: 페이스 분/km (/km) · 걸음 케이던스 spm · GPS와 심박 중심
페이스는 숫자가 작을수록 빠릅니다. 마일 단위에서는 /mi로 표시됩니다.
화면 이미지는 기존 자전거 화면 예시를 포함합니다. 앱 버전·종목·센서에 따라 메뉴와 표시값이 달라질 수 있습니다. 오늘의 러닝 계획·30분 달리기 입문은 해당 메뉴가 표시되는 버전과 계정에서 이용할 수 있습니다. 웹 매뉴얼에서 큰 화면의 기록·분석 흐름도 확인하세요.
