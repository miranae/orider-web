오라이더 웹 설명서

사이클과 러닝 기록을 확인하고, 컨디션을 읽고, 코치와 함께 다음 운동을 정하는 방법을 처음부터 차례로 안내합니다. 앱에서 기록하고, 웹에서 되짚어 봅니다.

왼쪽 목차(휴대폰에서는 위쪽 ☰ 메뉴)에서 장을 고르거나, 목차의 검색으로 용어·메뉴 이름을 바로 찾으세요. 2026년 10월 화면 기준이며, 그림은 실제 계정 화면입니다.

처음이라면 이 순서로

  1. 로그인하고 메뉴 5개를 둘러봅니다.
  2. 처음 해 둘 설정 — 훈련 기준값, 공개 범위, 기록 가져오기.
  3. 홈·운동일지에서 내 기록을 찾고 활동 상세를 엽니다.
  4. 코치 > 컨디션에서 오늘 상태를 보고, 목표를 세웁니다.

하고 싶은 일로 찾기

  • 러닝 시작: 러닝을 처음 확인할 때 → 페이스·구간 읽기 → 러닝 대회·30분 달리기
  • 사이클 실력 보기: 파워 읽기 → 파워 커브 → 세그먼트 순위
  • 숫자가 비었거나 '가정값'이 보일 때: 데이터 충분도·가정값
  • 함께 달리기: 클럽·친구·이벤트
  • 내 데이터 관리: API 키 · 내보내기·삭제 · 계정 삭제 요청

휴대폰 앱 사용법은 앱 설명서에 있습니다.

1. 시작하기
로그인, 메뉴 5개와 버튼, 종목 칩, 처음 해 둘 설정
2. 기록 보기 — 홈·운동일지·연간 기록
최근 7일, 월 캘린더, 한 해 기록, 파일 올리기
3. 활동 분석 — 사이클·러닝
지도·지표 카드, 분석·구간 탭, 편집·공개 범위
4. 비교·탐색 — 코스·세그먼트·챌린지·게시판
다음 코스 고르기, 구간 순위, 거리 도전, 글쓰기
5. 클럽·친구·이벤트
클럽 가입·운영, 이번 주 순위, 친구 맺기, 대회
6. 컨디션·체력 — 코치 > 컨디션·분석
CTL·ATL·TSB, 파워 커브, 가정값, 훈련 기준값
7. 코치 — 오늘 운동·계획·목표·대화
목표 세우기, 주간 플랜, 오늘 고르기, AI 코치
8. 종목별 읽기·멀티스포츠
러닝 페이스·GAP·케이던스, 수영, 통합 부하
9. Strava·연결 앱
연결, 과거 활동 가져오기, 자동 업로드, 헬스 소스
10. 설정
계정·공개 범위, 기기, API 키, 내보내기, 계정 삭제
11. 자주 묻는 질문
기록이 안 보일 때, 숫자가 비었을 때, 메뉴 찾기
